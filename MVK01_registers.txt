МВК01 — ПОЛНЫЙ ПЕРЕЧЕНЬ РЕГИСТРОВ MODBUS/TCP (ПО версии 1.0.61)
========================================================================
Все адреса — в 16-битных регистрах Modbus (hex). Длина указана в байтах.
Общая карта адресного пространства:
  0x0000–0x0FFF — Конфигурационные параметры        — Чтение и запись
  0x1000–0x1FFF — Системные параметры                — Только чтение
  0x2000–0x3FFF — Расчётные параметры (по каналам)    — Только чтение
  0x4000–0x4FFF — Расчётные параметры (по номерам)    — Только чтение
  0x8000–0x8FFF — Конфигурация расшир. диагностики    — Чтение и запись (не описывается)
  0x9000–0xA000 — Результаты расшир. диагностики      — Только чтение (не описывается)

Формат «Системная команда/статус выполнения» (п.3.1.2):
  0x10001 — Команда: Восстановить конфигурацию из Flash
  0xF0001 — Команда: Сохранить текущую конфигурацию во Flash (таймаут ответа увеличить до 3с)
  0xA0001 — Команда: Перезапустить устройство
  0x00000 — Статус: Операция успешно выполнена
  0x00BAD — Статус: Клиент записал неверную команду
  0xF0BAD — Статус: Ошибка флэш-памяти, конфигурация не сохранена

Формат «Порядок передачи байт» (п.3.1.4):
  0x00000000 — Big Endian (по умолчанию)
  0x99999999 — Смешанный режим (для ВДМ82)
  0x66666666 — Little Endian

РАЗДЕЛ 3.2.1 — ПАРАМЕТРЫ ИЗМЕРИТЕЛЬНЫХ КАНАЛОВ АЦП (Чтение/Запись)

Блок на канал: 256 регистров. Базовый адрес A = 0x100 + (N-1)×0x100, N = 1..8

№  Параметр                                              Адрес     Длина        Примечание
1  Тип канала                                             A+0x00    4            = 0
2  Коэффициент преобразования датчика                     A+0x02    4, float     В/(м/с2) для МВК

4  Резерв (коэффициент пересчёта)                         A+0x0E    4, float     не писать, считается устройством
5  Наименование единиц измеряемой величины датчика        A+0x10    8×4, char    по умолчанию «м/с2»
6  Серийный номер датчика                                  A+0x20    8×4, char
7  Фильтр X…25 кГц — номер нижней частоты среза            A+0x3E    4            0-выкл, 1-6.4кГц, 2-10кГц, 3-15кГц
8  Фильтр 1 — номер нижней дольоктавы                      A+0x40    4            номера см. 5.1.3
9  Фильтр 1 — номер верхней дольоктавы                     A+0x42    4
10 Фильтр 2 — номер нижней дольоктавы                      A+0x44    4
11 Фильтр 2 — номер верхней дольоктавы                     A+0x46    4
12 Макс. допустимое пост. напряжение на датчике            A+0x50    4, float
13 Мин. допустимое пост. напряжение на датчике             A+0x52    4, float
14 Конфигурация основного контролируемого параметра        A+0x60    32           см. 3.2.2
15 Конфигурация контролируемых параметров 2-8              A+0x70    7×32

Пример адресов начала блока по каналам:
  Канал 1: A = 0x100   Канал 2: A = 0x200   Канал 3: A = 0x300   Канал 4: A = 0x400
  Канал 5: A = 0x500   Канал 6: A = 0x600   Канал 7: A = 0x700   Канал 8: A = 0x800

  Пример: версия 1.7.20.0 → 0x01071400

Формат «Индикатор системных ошибок» (п.4.1.3):
  бит 0   — ошибка приёма данных от DSP
  биты 1-3 — ошибка работы с SD-картой
  бит 4   — ошибка отправки данных к DSP
  бит 5   — ошибка инициализации Modbus/TCP
  бит 6   — ошибка CRC при чтении конфигурации (загружена конфигурация по умолчанию)

Формат «Состояние контроля по агрегату» (п.4.1.4):
  биты 0-7   — номер зоны (0x11-зелёная, 0x12-отказ датчика, 0x13-неверная конфиг.,
               0x14-жёлтая, 0x15-красная, 0x00-не определено)
  биты 8-15  — события (бит 9-отказ датчика, бит 10-переход в жёлтую, бит 11-переход в красную)
  биты 16-31 — резерв

Формат «Индикаторы работы DSP» (п.4.1.5):
  1. Индикаторы перегрузки — 4 байта (биты 0-7 = каналы 1-8)
  2. Флаги ошибок конфигурации — 4 байта (бит 30-число каналов, бит 31-режим контроля)
  3. Счётчик выполненных процедур расчётов параметров — 4 байта

РАЗДЕЛ 5.1.2 — РАСЧЁТНЫЕ ПАРАМЕТРЫ КАНАЛОВ АЦП, адресация ПО НОМЕРАМ ПАРАМЕТРОВ
========================================================================
(Только чтение; доступно только в ПО версий 1.0.61 и новее)
Дублирует значения из 5.1.1 (кроме амплитуды/фазы гармоник) в другом порядке —
все 8 каналов подряд для одного параметра, удобно для чтения одним запросом.

№ параметра   Параметр                                         Адрес                  Длина
N = 1…184     8 значений параметра N для каналов 1…8            0x4000 + (N-1)×16      184×8×4

Примеры:
  N=1  (Напряжение на датчике, все 8 каналов):  адрес 0x4000
  N=2  (1-я полоса дольоктавного спектра, 8 каналов): адрес 0x4010
  N=48 (СКЗ виброускорения X…25кГц, 8 каналов): адрес 0x4000+(48-1)×16 = 0x41F0

========================================================================

  Тахометр 1: A = 0x3000     Тахометр 2: A = 0x3100

  0x00 — частота меньше минимально допустимой

  0x03 — вращение от тахометра 2 к тахометру 1

========================================================================
СПРАВОЧНО: ФОРМАТ ПАКЕТА MODBUS/TCP
========================================================================
Идентификатор транзакции      2 байта   (на усмотрение клиента, копируется в ответ)
Идентификатор протокола        2 байта   = 0
Длина пакета (без этих 4 байт) 2 байта   от 2 до 257
Идентификатор устройства       1 байт    = 1
Код функции                    1 байт    0x03-чтение, 0x10-запись, 0x83-ошибка чтения, 0x90-ошибка записи
Содержимое                     0-255 байт

Функция 0x03 (чтение): запрос — адрес первого регистра (2 б) + кол-во регистров R (2 б, 0-125)
                        ответ  — кол-во байт данных N=R×2 (1 б) + данные (N байт)
Функция 0x10 (запись): запрос — адрес первого регистра (2б) + кол-во регистров R (2б) +
                        кол-во байт N=R×2 (1б) + данные (N байт)
                        ответ  — адрес первого записанного регистра (2б) + кол-во регистров (2б)
Ошибка: код ошибки — 1 байт
========================================================================
