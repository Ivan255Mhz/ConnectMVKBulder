# Mvk.Benchmarks

Read-only бенчмарк реальных устройств МВК01. Подключается к диапазону
`10.20.0.203…10.20.0.210`, измеряет задержки операций, p50/p95/p99,
приблизительные аллокации на операцию и параллельную пропускную способность.

Запись конфигурации и системные команды не используются.

## Запуск

```powershell
dotnet run --project benchmarks\Mvk.Benchmarks -- --iterations 20 --warmup 3
```

Параметры:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--hosts` | `10.20.0.203..210` | Список адресов через запятую |
| `--iterations` | `20` | Измеряемых итераций на операцию |
| `--warmup` | `3` | Прогревочных итераций |
| `--delay-ms` | `5` | Пауза между измерениями, мс |
| `--channel` | `1` | Канал 1–8 |
| `--measurement` | `55` | Номер параметра 1–184 |
| `--no-parallel` | выключено | Не запускать параллельную стадию |
| `--help` | — | Справка |

## Что измеряется

- `ReadDeviceInfoAsync` — 1 запрос;
- `ReadChannelAsync` — 5 запросов (совместимость);
- `ReadChannelSnapshotAsync` — 3 запроса с проверкой копий;
- `ReadChannelConfigAsync` — 1 запрос;
- `ReadTachoAsync` — 1 запрос;
- `ReadValuesAsync` — 1 запрос;
- параллельное чтение параметра со всех устройств.

`alloc/op` — приблизительная оценка через `GC.GetTotalAllocatedBytes`: она
включает служебные аллокации процесса и не является точным профилем одного
запроса. Для точных микробенчмарков используйте BenchmarkDotNet отдельно.
